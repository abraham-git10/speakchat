### Keyboard Controls

| Context | Key / Shortcut | Action |
| :--- | :--- | :--- |
| **Main Menu** | `Tab` | Cycle through inputs, lists, and buttons. |
| **Main Menu** | `F1` | Start reading contacts out loud in alphabetical order. |
| **Main Menu** | `F2` | Repeat server connection status instructions. |
| **Main Menu** | `F3` | Select the currently spoken contact to launch a chat session. |
| **Main Menu / Chat** | `F4` | Exit/close current active window. |
| **Chat Window** | `Enter` | Send typed message. |
| **Chat Window** | `Shift + Enter` | Insert a line break in the chat box. |
